TL;DR

One psychological account defines creativity as constrained problem solving, shaped by five situational factors: pressure, pleasure, opportunity, prototypes, and helpers. We evaluate LLM creativity by imposing constraint and varying its situational factors on two math benchmarks, and we improve it by introducing a proposer–composer harness based on stage theories of creativity: a small proposer brainstorms candidates, which a larger composer develops into its own answer.

Background

Creativity as constrained problem solving

A solution is creative when it meets the problem’s constraints effectively and economically. Creativity starts once the conventional route to a solution is closed and another has to be found.

Constraints and Creativity: In Search of Creativity Science (2021), Kupferberg

OMEGA-Constraint and Omni-MATH-Constraint

We pair every problem from two math benchmarks, OMEGA and Omni-MATH, with versions that close the conventional route while another stays open. The conventional route is the reference solution, and each of three constraints closes it differently. The three constraints, alone and combined, give 2³ = 8 conditions, including the baseline; we call this the constraint grid. A response that violates any active constraint counts as wrong.

Tools, threats and rewards

We add tool access as opportunity. Here the conventional route is a Python library. Models act as agents for up to six steps, each a Python tool call or a text reply. The open condition allows every available library; the ban condition forbids the reference solution’s library, and a banned call returns an error. Since OMEGA is near saturation without tools, this condition runs on the unconstrained Omni-MATH problems.

Contribution 2

Solution-preserving perturbations

We vary incidental numbers or objects while keeping the conventional route open. On OMEGA, replacing the numbers alone costs models 8.9 to 15.2 points of accuracy, and a single problem swings by up to 15.2 points across its variants. Every variant keeps the solution, so a benchmark that scores each problem in one variant and from one sample cannot separate creativity from this sensitivity. Our evaluation compares each problem with its own constrained version and tests the paired difference, so we measure the cost of the constraint alone: how well a model solves once the conventional route is closed.

Distributing the creative process

We develop PCH on the task of the Divergent Remote Association Test (DRAT): given four remote cue words, produce ten semantically diverse nouns, each metaphorically associable with all four. Against the composer alone, we run ten proposers per composer: nine other models of 124M–3.8B parameters, plus a second instance of the composer, each in three modes: plain, prompted with SSoT, or divergent-word-tuned (fine-tuned on DRAT).

Conclusion

Creativity has to be built as a process

We evaluated creativity in language models as one psychological account defines it in humans: problem solving under constraint in a situation shaped by opportunity, pressure, and pleasure. Where constraint sharpens human creativity, models lose accuracy with each constraint added: banned methods return under new names, a withdrawn library leaves some models without an answer, while rewards and threats barely move accuracy. To improve creativity, we built PCH on stage theories of creativity, which raises the composer above what it achieves alone on every benchmark. Creativity in today’s language models therefore has to be built as a process; a prompt alone does not elicit it.
